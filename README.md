# Коммуналка — Android-приложение

Учёт показаний счётчиков и оплаты ЖКУ для нескольких квартир.

## Что умеет

- **Несколько квартир**: у каждой свои счётчики, тарифы, окно передачи показаний и фиксированные начисления.
- **Счётчики**: холодная и горячая вода, электричество (1, 2 или 3 тарифные зоны), газ, отопление; номер и дата поверки.
- **Распознавание показаний камерой**: у каждого поля ввода есть кнопка «Камера». Распознавание идёт прямо на телефоне (Google ML Kit), интернет не нужен. Приложение подбирает положение запятой по прошлому показанию и обычному расходу и предлагает до пяти вариантов — нажмите на верный.
- **Проверка ошибок**: показание меньше прошлого, расход в разы выше обычного, нулевой расход воды.
- **Расчёт суммы** по тарифам, с водоотведением и фиксированными услугами; сверка с суммой из квитанции.
- **Отметка оплаты** и история по месяцам; долги и сроки (до 10-го числа следующего месяца).
- **Уведомления** раз в день в выбранное время: открыто окно передачи показаний, подходит срок оплаты (за 5 дней), просрочен долг, скоро поверка.
- **Текст для управляющей компании** — отправить в мессенджер или скопировать.
- **Резервная копия**: сохранение всех данных в файл и восстановление из него (вкладка «Квартиры» → «Данные»).
- Тёмная тема, данные только на телефоне.

## Как получить APK без установки программ (через GitHub)

1. Зарегистрируйтесь на [github.com](https://github.com) (бесплатно).
2. Нажмите **New repository**, придумайте имя (например, `kommunalka`), можно сделать его **Private**, нажмите **Create repository**.
3. На странице репозитория выберите **uploading an existing file** (или **Add file → Upload files**).
4. Распакуйте архив на компьютере и перетащите **всё содержимое папки `Kommunalka`** в окно браузера, затем нажмите **Commit changes**.
   - Важно: должна загрузиться скрытая папка `.github`. На macOS скрытые файлы показываются сочетанием `Cmd + Shift + .`. После загрузки в репозитории должна быть видна папка `.github/workflows`.
5. Откройте вкладку **Actions** — сборка «Сборка APK» запустится сама. Первая сборка идёт 5–10 минут.
   - Если сборка не стартовала, выберите её слева и нажмите **Run workflow**.
6. Когда появится зелёная галочка, откройте сборку и внизу в разделе **Artifacts** скачайте `kommunalka-apk`. Внутри zip — APK-файл.
7. Перекиньте APK на телефон (почта, мессенджер, кабель), откройте его и разрешите установку из этого источника.

Если сборка завершилась с ошибкой (красный крестик), откройте её, нажмите на шаг «Собрать APK» и скопируйте текст ошибки — по нему можно быстро исправить код.

## Постоянный ключ подписи (рекомендуется, делается один раз)

Без него GitHub собирает отладочную версию, подписанную случайным ключом, который меняется при каждой сборке. Из-за этого новая версия не установится поверх старой: придётся удалять приложение вместе с данными. Кроме того, отладочную версию можно прочитать по USB-кабелю. С постоянным ключом собирается обычная release-версия, и обновления ставятся поверх.

1. Вкладка **Actions** → слева **«Создать ключ подписи (один раз)»** → **Run workflow**.
2. Когда сборка завершится, скачайте из неё артефакт `signing-key-SECRET` и распакуйте. Внутри три файла.
3. Откройте **Settings → Secrets and variables → Actions → New repository secret** и создайте два секрета:
   - `KEYSTORE_B64` — всё содержимое файла `KEYSTORE_B64.txt`;
   - `KEYSTORE_PASSWORD` — содержимое файла `KEYSTORE_PASSWORD.txt`.
4. Файл `release.jks` и пароль сохраните в надёжном месте (например, в менеджере паролей) — без них нельзя будет выпускать обновления. Артефакт с ключом GitHub удалит сам через сутки; удалите и скачанную папку.
5. Запустите «Сборка APK» заново (**Actions → Сборка APK → Run workflow**) — теперь соберётся подписанная версия.

Если отладочная версия уже установлена, перед первой установкой подписанной сохраните резервную копию данных, удалите старое приложение, установите новое и восстановите данные из копии.

Репозиторий лучше делать **приватным**: тогда к артефактам и сборкам есть доступ только у вас.

## Сборка в Android Studio

1. Установите [Android Studio](https://developer.android.com/studio).
2. **File → Open** → выберите папку `Kommunalka`. Studio сама скачает Gradle и библиотеки.
3. Подключите телефон с включённой отладкой по USB и нажмите **Run**, либо **Build → Build APK(s)**.

## Технологии

Kotlin, Jetpack Compose (Material 3), CameraX, ML Kit Text Recognition (офлайн), WorkManager. Минимальная версия Android — 8.0.

## Ограничения

- Данные хранятся только на телефоне (файл во внутренней памяти приложения), синхронизации между устройствами нет. Для переноса и подстраховки используйте резервную копию; файл копии не зашифрован, храните его в надёжном месте.
- Время напоминания приблизительное: Android может сдвинуть его ради экономии батареи. На некоторых телефонах (Xiaomi, Huawei и др.) стоит разрешить приложению работу в фоне.
- Распознавание лучше всего работает на механических счётчиках с барабанами при хорошем освещении; на ЖК-дисплеях электросчётчиков — хуже. Значение всегда можно поправить вручную.
- Распознавание выполняет библиотека Google ML Kit прямо на телефоне; изображения никуда не отправляются, но библиотека может передавать Google обезличенную статистику работы.
